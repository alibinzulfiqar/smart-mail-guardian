# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with monorepo setup
- Next.js 14 dashboard with App Router
- NestJS API Gateway with authentication
- Email integration service (Gmail, Outlook, IMAP)
- Python AI engine for threat detection
- PostgreSQL database with Prisma ORM
- Redis-based job queues with BullMQ
- Docker Compose configuration
- Phishing detection with pattern matching
- Spam detection with content analysis
- Social engineering detection
- URL scanning and brand impersonation detection
- Attachment risk analysis

### Security
- JWT-based authentication with refresh tokens
- Password hashing with bcrypt
- Rate limiting on API endpoints
- CORS configuration
- Environment variable configuration
